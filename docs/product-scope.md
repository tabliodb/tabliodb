# Product Scope

MVP Tabliodb sengaja tidak dibuat miskin fitur. Fondasi awal harus sudah memberi tempat untuk:

- organizations dan project membership
- diagram canvas dengan table, column, enum, index, relationship, note
- realtime editing dengan Yjs dan Hocuspocus
- live cursor/presence melalui awareness
- comments di target schema entity
- version snapshots
- PostgreSQL dan MySQL SQL generator
- API key dan SDK untuk integrasi
- future-ready migration diff/review

Fitur yang boleh ditunda: direct database connection importer, schema branching, migration-aware ALTER generator penuh, dan multi-instance realtime scaling lewat Redis.
